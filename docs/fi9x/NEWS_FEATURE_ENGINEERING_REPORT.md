HIGH quarters coincide with **less** news volume. The archive's volume fell over the same years that hunger rose, so raw volume measures attention and collection, not conditions. All features are therefore coverage-normalised. The stress index has almost no marginal correlation with the outcome. Any value of news has to come through interaction with the latest reading, which is what the fusion experiments test.
