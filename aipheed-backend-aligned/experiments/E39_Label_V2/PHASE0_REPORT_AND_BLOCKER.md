### 4. Per date: H, τ, mean D, S1 spread, HIGH count (lead-1 origins)

- **τ lags H:**
  - τ rises from 10.8 (2023) to 14.8 (2026-Q3) while H rises to 19.6–25.3 (2024–2026);
  - **H alone exceeds τ on 13 of 17 labelled dates.**
- Over 17 dates: 60/85 HIGH; **all five provinces are HIGH on 6 dates.**
- Mean D is 0 on every date by construction. Provinces differ only through D, with a spread of 3.6–14.7 S1 points.

### 5. Verdict

**v1 has no arithmetic bug.**
- Every S1 reproduces from raw files within PSA's own rounding.
- No label changes.
- τ uses only posted labels.

**v1 has design flaws:**
1. The trailing-median τ lags an upward trend in H, so HIGH is mostly "hunger above its own past".
2. It adds percent of families and percentage points with an unjustified weight of 2.
3. D is de-meaned, so price stress shared by all five provinces is invisible.
4. One regional H dominates, so provinces are barely separated.
5. The display layer uses tie ranks (consecutive ranks for equal scores) and a fixed 0.5 band on unvalidated probabilities.

## Phase 1: STOPPED. The anchor rules cannot be met

The task requires anchors defined on a reference window **before the first labelled quarter (2021-Q2)**, or documented external constants; otherwise stop and report.

| Anchor | What exists | Why it cannot be used under the current rules |
|---|---|---|
| **H_norm** = median of SWS Balance Luzon in the reference window | **No approved SWS round before 2021-Q2 exists in the study window.** 2021-Q1 has none; the first approved rounds are April–June 2021. | Any pre-2021 SWS value is excluded by your standing rule: no data before 2021-Q1 may enter any threshold or claim (study-window rule, 2026-10-14). No documented external "normal hunger" constant is known that is not itself computed from pre-2021 SWS rounds. |
| **H_sev** = documented pandemic-peak SWS value | The pandemic peak was in **2020**. | Pre-2021, so excluded by the same rule. The in-window maximum (2024-Q4, 25.3) would be "a maximum over the evaluation sample", which the task forbids. |
| **P_norm** = 4% | The BSP/DBCC inflation target of 3% ± 1 point (upper end 4%) is a documented policy constant, not data. | **Usable**, with two stated caveats: it is a **headline** CPI target applied to **provincial food** inflation, and the source page still has to be cited exactly (not fetched in this run). |
| **P_sev** = 95th percentile of provincial food YoY in the reference window, or an official threshold | In-window, pre-label data = **2021-Q1 only**: 5 quarterly values (15 months). | A 95th percentile of 5–15 values is effectively their maximum. A wider window needs pre-2021 data (excluded). No official "severe food inflation" threshold is known. |

**Result:** three of the four anchors (H_norm, H_sev, P_sev) cannot be justified from a documented source without breaking the study-window rule. As the task instructs:
- I did not invent values;
- I did not substitute in-sample statistics;
- I did not build `label_v2_spec.json`.

Phases 1–6 have not started:
- no specification;
- no labels;
- no model run;
- no scoring;
- no workbook.

## What would unblock it (your decision; any of these must be recorded before any model run)

1. **A written, narrow exception to the study-window rule for label anchors only.** For example:
   - SWS Balance Luzon approved rounds for a stated pre-2021 window (such as 2015–2019) define H_norm;
   - the 2020 pandemic-peak Balance Luzon value defines H_sev;
   - provincial food YoY 2015–2019 defines P_sev.

   The values would come from files you supply, or from SWS/PSA pages for those years that you authorize me to fetch. Pre-2021 data would still never enter training, features or evaluation.
2. **Adviser-set constants.** H_norm, H_sev and P_sev are written in a dated decision record by you or your adviser with a stated basis. They are then "documented methodological choices", and the report says so.
3. **Drop the absolute H component.** Build the index from components that can be anchored in-window. This changes the task's specification, so it needs your instruction.
