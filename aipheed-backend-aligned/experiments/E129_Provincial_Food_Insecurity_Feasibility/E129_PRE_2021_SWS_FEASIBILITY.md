# E129 pre-2021 SWS feasibility

**Data already held.** `E114_Final_Run/data/sws_area_rounds_full.csv`, 115 area rounds, 1998-Q3 .. 2026-Q3. Collected for E114 analysis (b) under an E114-only exception.

| Aspect | Finding |
|---|---|
| Coverage | 92 rounds 1998-Q3 .. 2020-Q4; about 4 per year; Balance Luzon every round |
| Geography | Still Balance Luzon. **Pre-2021 data add regional quarters, not provinces.** |
| Survey mode | Face-to-face, except 3 mobile-phone rounds in 2020 (May, July, September; COVID). Those show 12.6–23.8 % and are not comparable without adjustment. |
| Question | The involuntary-hunger item ("experienced hunger and had nothing to eat in the past 3 months") is SWS's long-standing item. Wording continuity is asserted in SWS releases but not independently verified here. |
| Sampling | National n mostly 1,200 (BL about 300 → 600 in older rounds; per-round n unverified for many years). Precision is lower than 2021+. |
| Publication timing | Release dates for 92 pre-2021 rounds are **rule-based** (label month end + 60 days), not verified. Point-in-time use needs dated releases. |
| Prior use | E114 scored 2013–2020 once as an untouched test. That period is now inspected too. |
| Owner rule | The study window is 2021+ (`study_window_2021_2026`). Pre-2021 data were allowed for E114 analysis (b) only. |

## Would pre-2021 data help?

**Regional forecasting: yes, plausibly.**
- About 90 more quarters would make R1 attainable (≥ 10 quarters and ≥ 40 rows at every lead) for a regional target.
- E114 found level-forecast skill over persistence on 2013–2020.
- The 11.3 threshold would need re-justifying. The long-run median is 13.8.

**Provincial forecasting: no.** Every pre-2021 value is Balance Luzon.

## Not included automatically

**Using pre-2021 SWS needs an owner decision to widen the window, plus:**
- verified release dates, or a conservative publication lag;
- the 2020 phone rounds excluded or flagged;
- a stated comparability assumption for the hunger item.

E129 recommends it only as a **separate regional track**. It does not touch the provincial target question.
